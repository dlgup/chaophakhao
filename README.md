# Chao Pha Khao: Wings of Fury

An educational vertical shooter about the Secret War in Laos, made by David Lee and Hmongstory Legacy for Yav Pem Suab Academy. Copyright Hmongstory Legacy 2026.

The whole game is one file, `index.html`. Netlify serves it as a static site with no build step. Edit `index.html`, commit to `main`, and the site updates.
